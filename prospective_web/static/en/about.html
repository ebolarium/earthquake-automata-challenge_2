RESEARCH QUESTION

Across tectonically distinct regions, does a frozen causal spatial correction to ETAS achieve positive prospective information gain without degrading CSEP count and likelihood calibration?

This is not a public earthquake warning product. It is a prospective shadow test in which daily spatial rate forecasts are published before their target window and scored only after events occur.

Causal gate

Completed-day fixed-versus-safe event log ratios accumulate in shadow mode. The next forecast weight is fixed as:

w = max(0, tanh((S − log 20) / 2))

The prospective state starts at S=0; retrospective evidence is not carried forward. BF20 is an operational evidence hurdle, not an unconditional 5% false-activation guarantee.

Scoring

IGPE(M, ETAS) = Σ log[λM(i)/λETAS(i)] / N

Safety reporting also gives fixed and gated IGPE relative to the safe incumbent. Every layer preserves the same daily expected count, so the paired compensator difference is zero. Conditional-Poisson spatial CSEP N, L, and R tests are published daily and cumulatively for each region.

Prospective integrity

  • Forecast artifacts are timestamped and SHA-256 locked before the target day.
  • Backfill is prohibited.
  • The first score is provisional and the seven-day catalog snapshot is final.
  • There is no additional 14-day dry run; the 365-day clock begins only after one complete four-region issue.
  • The seven-day interval is catalog settlement, not a pause in forecasting.

Limitations

The method was developed after California, New Zealand, Chile, and Japan-C outcomes were opened. Those results are not independent confirmation. The retrospective gate removed large negative transfer but retained a very small Chile loss; the prospective test targets that unresolved question.
